Cara Online-kan ke Vercel.app (Gratis 1 Menit)
  1. Buka vercel.com dan login menggunakan akun GitHub/Google.
  2. Upload folder aplikasi ini ke GitHub atau drag-and-drop menggunakan Vercel CLI.
  3. Aplikasi Anda langsung aktif dengan alamat nama-aplikasi.vercel.app!
Sinkronisasi Cloud Antar Perangkat (Opsional) Supabase Gratis

Secara bawaan, data langsung tersimpan otomatis di browser (LocalStorage). Jika Anda ingin beberapa orang menginput dari HP berbeda dan datanya menyatu otomatis, masukkan URL & Anon Key Supabase gratis Anda:

Lihat SQL pembuatan tabel Supabase (klik di sini) 
create table transactions (
  id text primary key,
  inputter text not null,
  type text not null,
  amount numeric not null,
  category text not null,
  method text not null,
  note text not null,
  date text not null,
  created_at timestamptz default now()
);
alter table transactions enable row level security;
create policy "Public access" on transactions for all using (true) with check (true);
