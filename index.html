Pengaturan Cloud & Deploy Vercel.app

Gunakan penyimpanan lokal otomatis atau sambungkan ke database cloud bersama

Cara Online-kan ke Vercel.app (Gratis)

  1. Klik 2x file deploy-ke-vercel.bat di folder proyek ini, atau upload ke GitHub.
  2. Buka vercel.com dan pilih repository proyek ini.
  3. Aplikasi langsung online dengan domain nama-aplikasi.vercel.app.
