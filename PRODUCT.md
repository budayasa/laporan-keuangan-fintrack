# FinTrack Pro — Product Context

## Overview
FinTrack Pro adalah aplikasi web pencatatan dan rekapitulasi laporan keuangan (Buku Besar Kas) yang dirancang untuk kemudahan pencatatan harian oleh banyak penginput dan siap di-deploy ke `vercel.app`.

## Primary Mode
- **Operate**: Antarmuka kerja untuk mencatat transaksi pemasukan dan pengeluaran secara cepat, memantau neraca kas secara real-time, memfilter jurnal berdasarkan penginput/periode, serta mengekspor atau mencetak laporan resmi.

## Core Capabilities
1. Pencatatan siapa yang menginput beserta pilihan cepat nama penginput.
2. Pencatatan tanggal dan waktu otomatis secara real-time (dengan opsi ubah manual).
3. Input nominal Pemasukan (+) dan Pengeluaran (-) dengan format titik ribuan otomatis.
4. Tabel Pemasukan dan Tabel Pengeluaran terpisah maupun jurnal gabungan.
5. Rekapitulasi keseluruhan (neraca bersih, rekap per penginput, per kategori, per bulan, serta kontrol batas anggaran).
6. Visualisasi grafis tren arus kas, kurva saldo berjalan, proporsi kategori, dan kontribusi per penginput.
7. Ekspor ke Excel (CSV), Cetak PDF bertanda tangan, Kirim Rekap ke WhatsApp, Cadangan JSON, dan sinkronisasi opsional Supabase Cloud.
